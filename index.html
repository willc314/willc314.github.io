Room Mapping Finch

Autonomous robot that maps a room using a PID controller and distance sensors.

Click to learn more »

Using the Finch 2.0 Robot, I created a program which uses a PID controller to navigate the robot around a room and maps its surrounding walls using its distance sensors.

The PID controller continuously adjusts the robot's heading based on sensor feedback, allowing it to follow walls smoothly and produce an accurate internal map of its environment. The mapping algorithm logs each detected wall segment relative to the robot's tracked position, building up a 2D representation of the room as the robot explores.

Tech used: Python, Finch 2.0 Robot SDK, PID control theory

Game: Power Up

A 2.5D roguelike game built in Unity with procedural levels and combat.

Click to learn more »

Power Up is a 2.5D roguelike game I created in Unity Version 2022.3.62f3. The game blends 2D character movement with 3D environments, giving it a unique visual style while keeping gameplay accessible.

Players progress through procedurally arranged rooms, fight enemies, and collect power-ups that modify the player's abilities for that run. The roguelike design means each playthrough is different, and dying restarts the run with new layouts and rewards.
